# Cow Creek Triplex prototype

Static site, no build step. Upload the contents of this folder to a GitHub repository and turn on GitHub Pages (Settings > Pages > Deploy from a branch > main / root).

- `index.html` asks for the preview password, then opens the sign-in screen.
- `login.html` signs in to either portal with any entry.
- `gov.html` and `member.html` are the desktop portals; `gov-mobile.html` and `member-mobile.html` are the phone versions.

The password page only hides the prototype from casual visitors. It is not real security: the files are public if the repository is public.
